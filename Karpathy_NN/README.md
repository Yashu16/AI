### Micrograd

What it does - A minimal Autograd engine built from scratch in Python, following Karpathy's Neural Networks: Zero to Hero series. 
Implements Backpropagation through a dynamically built computational graph. 

What it implements - Value Class, Forward and Backward pass along with a small neural network. 

What I learned -  How gradients change from input neurons - through hidden layers - to output neurons. And how backpropagation is implemented.
